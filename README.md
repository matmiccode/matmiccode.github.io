# matmiccode.github.io

Strona glowna MATCODE: https://matmiccode.github.io/

Wspolna rama stron programow lezy w `css/v1/matcode.css`. Strony poszczegolnych
programow (np. https://matmiccode.github.io/papuga/) sa publikowane z ich
wlasnych repozytoriow i korzystaja z tego arkusza pod adresem `/css/v1/`.
Nowa wersja ramy to nowy katalog (`css/v2/`), stare strony zostaja przy swojej.
